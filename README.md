# 知乎高赞回答归档

本站收录知乎话题下的高赞回答，并以 Markdown 形式展示。

## 在线访问

- GitHub Pages：https://zhaoweilong007.github.io/zhihuCrawler/

## 如何浏览

- 从左侧选择一个一级分类；目录仅在打开时加载，不会再一次性加载全部文章。目录右侧的“子目录数/文章数”方便判断内容规模。
- 进入文章后，正文会按需从归档分支读取并由 Docsify 渲染。
- 左侧搜索框支持全站标题搜索；只在提交关键词后加载搜索索引。
- 阅读页提供上一篇、下一篇、返回目录、进度条、字号/行距/版心调节、收藏和复制链接；最近阅读与收藏仅保存在当前浏览器。

[开始浏览](/browse)

> 当前站点已将首屏导航、目录索引、标题搜索与海量正文分离，避免浏览器解析全量目录树。
